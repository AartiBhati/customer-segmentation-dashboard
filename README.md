# Customer Segmentation and Sales Dashboard

## Project Overview
This project analyzes retail sales data and performs customer segmentation using RFM analysis and Tableau dashboard.

## Tools Used
- Python (Pandas, Matplotlib)
- Tableau
- GitHub

## Project Steps
1. Data Cleaning
2. Exploratory Data Analysis
3. RFM Customer Segmentation
4. Tableau Dashboard
5. Business Insights

## Insights
🧠 Sales Insights
The majority of revenue is generated from the United Kingdom.
Sales increase significantly during November and December, indicating seasonal demand.
Monthly sales trend shows strong growth during the holiday season.
A small number of customers contribute a large portion of total revenue.

👥 Customer Insights
Loyal customers and Champion customers contribute the highest revenue.
Some customers fall into the “At Risk” category and may require retention strategies.
Customer segmentation shows that repeat customers are very important for revenue.

📈 Business Recommendations
The company should focus on retaining loyal and champion customers.
Marketing campaigns should target at-risk customers.
Inventory should be increased before the holiday season due to high demand.
