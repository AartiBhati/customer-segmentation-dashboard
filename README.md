# Customer Segmentation and Sales Dashboard

## Project Overview
This project analyzes retail sales data and performs customer segmentation using RFM analysis and Tableau dashboard.

## Tools Used
- Python (Pandas, Matplotlib)
- Tableau
- GitHub

## Project Steps
1. Data Cleaning
2. Exploratory Data Analysis
3. RFM Customer Segmentation
4. Tableau Dashboard
5. Business Insights

## Insights
- UK generates most revenue.
- Sales peak during November and December.
- Loyal and Champion customers contribute most revenue.
- Some customers are at risk and need retention strategies.
